# Caixa da Sorte - Site de Loteria

![Logo do Projeto](./imagens/logo_zap.jpg)

Bem-vindo ao **Caixa da Sorte**, um site dedicado a fornecer informações atualizadas sobre as principais loterias da Caixa Econômica Federal. Aqui, os usuários podem encontrar detalhes sobre jogos como Mega-Sena, Quina, Lotofácil, entre outros.

## Sobre o Projeto

O **Caixa da Sorte** foi desenvolvido com o objetivo de centralizar informações relevantes sobre as loterias da Caixa, facilitando o acesso dos usuários a resultados, datas de sorteios e dicas para apostas.

## Tecnologias Utilizadas

- **HTML5**: Estruturação e conteúdo das páginas.
- **CSS**: Estilos e layout responsivo.
